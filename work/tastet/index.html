Tastet — research-funded recsys, deployed in production

A hybrid recommender system for Montréal's gourmet guide — from supervised research at HEC Montréal to a live, retraining production system on GCP.

Recommender SystemsRankingGCPDockerFairnessMitacs $15K+

The challenge

Tastet is a culinary guide built on equity and diversity — so a recommender that simply maximized clicks would have betrayed the product. Popular restaurants would dominate; small merchants would disappear. The system had to balance accuracy with merchant equity, and it had to run lean on a startup budget.

Benchmarking with two scoreboards

I benchmarked 8 ranking models — KNN, ALS, SVD, RankFM, cosine similarity, item popularity, multivariate normal, and hybrids — against two metrics at once: F1-score for accuracy, and a custom fairness metric measuring how recommendation exposure distributed across merchants. The winning hybrid traded a little precision for a lot of equity — a deliberate, measured decision rather than a vibe.

Production architecture

User/merchant registration event
        ↓
GCP Cloud Functions (event-driven triggers)
        ↓
Data collection → Google Cloud Storage
        ↓
Weekly cron-based retraining + refresh
        ↓
Docker container serving a real-time recommendation API

Event-driven where the data changes, scheduled where the model needs refreshing, containerized where it serves. Boring in the best possible way — it kept running.

Research to production, funded

The project ran as supervised research at HEC Montréal with Prof. Laurent Charlin, secured multiple rounds of Mitacs funding ($15,000+), and produced a thesis on state-of-the-art recommender systems and ethical AI. Most funded research ends as a PDF. This one ended as an API serving real users.
