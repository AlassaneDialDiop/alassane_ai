Olima — a game built on 64-dimensional embedding space

A mobile self-discovery game where every "pick a celebrity" choice is secretly a step through spectral embedding space — and the AI narrates what your taste reveals.

EmbeddingsRecommender SystemsMulti-LLM OrchestrationReact Native / ExpoWikidata

The core idea

Personality tests ask you to describe yourself. Olima never asks — it watches. Users pick who they'd sit next to on a flight; under the hood, each pick is a direction in a 64-dimensional spectral embedding space. Famous people are just the marketable wrapper around geometric vectors.

Behavioral data over knowledge graphs

The similarity model is built from Wikipedia clickstream co-occurrence — how millions of humans actually navigate between people — rather than a curated knowledge graph. The result is behaviorally correct similarity: Messi's nearest neighbor is Cristiano Ronaldo at 0.9967, not a taxonomically "correct" but boring answer. Entities are keyed by Wikidata QIDs, so identities stay stable across embedding versions and analytics survive model upgrades.

A deterministic engine where it counts

Each round serves five rows, each one a geometric move relative to the user's profile: similar (continue the direction), different (opposite), two diversity rows that maximize tetrahedron volume in embedding space, and a hub anchor weighted by popularity so there's always a recognizable face. The profile evolves by EWMA — profile = 0.7·profile + 0.3·selection — so it converges smoothly instead of lurching after one pick.

Because selection is pre-computed geometry rather than an LLM call, a session costs about $0.002 — which is what makes an unlimited free tier economically survivable. The LLMs are reserved for what they're actually good at: narration.

Multi-LLM orchestration

  • Gemini — visual asset generation pipeline
  • GPT-5 — the in-game mascot agent that turns choice patterns into a personal story
  • Claude — development workflow across the codebase

Shipped, not demoed

React Native / Expo client at 60fps without canvas hacks, responsive viewport strategy across iPhone/iPad/desktop, full analytics instrumentation (39 tracked events, PostHog + GA4 + Meta), email system, and deployment operations — all built and operated by one engineer. V12 is live at olima.ai.

What this demonstrates

  • Recsys depth — embedding construction, geometric candidate selection, profile evolution: a recommender system wearing a game costume.
  • Cost-aware AI architecture — deterministic where possible, generative where valuable.
  • Product engineering — one engineer covering data science, mobile, backend, analytics, and operations.
