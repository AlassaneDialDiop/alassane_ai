Case study · Data Scientist, ML Engineering · 2023–present

Browns Shoes — production ML for a national retailer

Four ML systems running inside one retail business: recommendations, visual search, LLM-powered customer insight, and natural-language analytics.

LLM PipelinesComputer VisionRecsysSnowflake CortexdbtMMM

Recommendation engine

Built and shipped a product recommendation engine that mines order-history patterns to personalize product grids across the full e-commerce catalog — powering customer communications with suggestions specific to each shopper.

Computer-vision shoe recognition

A visual search system: a user photographs a shoe, embeddings + semantic search match it against the catalog, and the system returns the product with full metadata. Multimodal retrieval applied to a concrete retail problem.

LLM pipeline for NPS feedback

Thousands of free-text customer comments used to be read by nobody. I designed an LLM-based pipeline that performs sentiment analysis and structured insight extraction over the full NPS stream — turning unstructured complaints and praise into a queryable, trackable signal for the business.

Natural-language analytics on Snowflake Cortex

Led the migration to a Snowflake Cortex REST API gateway with a carefully designed semantic layer, so business users can ask questions in natural language and get correct SQL against governed definitions. Underneath: a multi-project dbt architecture with RBAC supporting the ML feature pipelines.

Measured impact

Built a Marketing Mix Model (MMM) quantifying ROI per paid channel; its recommendations drove roughly a 20% reduction in marketing spend while maintaining revenue.

What this demonstrates

  • Breadth in production — recsys, CV, LLM, and causal/statistical modeling, all live inside one business.
  • Modern data stack fluency — Snowflake Cortex, dbt, semantic layers, RBAC.
  • Business translation — every system maps to a revenue, cost, or customer-experience outcome.
